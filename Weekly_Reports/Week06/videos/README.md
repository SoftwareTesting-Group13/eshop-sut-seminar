# Thư mục lưu trữ Video Clip Demo của Tuần 6

Theo quy định chuẩn đầu ra môn học (Deliverables Stage S4):
* **File chính thức:** `Demo_Screencast.mp4`
  * Thời lượng: **5 – 8 phút** (tối đa 8 phút).
  * Độ phân giải: **1080p (Full HD)**, 60fps.
  * Thuyết minh: **100% Tiếng Anh (English Narration)** rõ ràng, chuẩn ngữ điệu, **không nhạc nền**.
  * Dung lượng: **≤ 100MB** (nén tối ưu bằng ffmpeg / Handbrake).
  * Nội dung: Quay trực tiếp màn hình IDE/Terminal/GitHub Actions thật (tuyệt đối không chiếu slide câu giờ).

### File nháp / đoạn cắt ngắn cá nhân:
Nếu các thành viên có clip quay thử hoặc clip demo riêng từng phân đoạn, đặt tên có tiền tố:
* `[tên-thành-viên]_[nội-dung-clip].mp4` (Ví dụ: `ncuong_raw_pipeline_demo.mp4`, `mtuan_raw_coupon_demo.mp4`).
* File chính thức nộp seminar đặt tên chuẩn: `Demo_Screencast.mp4`.
