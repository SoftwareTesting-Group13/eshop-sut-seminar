# Thư mục lưu trữ Chat Log / Prompt Log với AI của Tuần 6

Quy định lưu trữ các file chat log / prompt log trao đổi với AI của từng thành viên trong Tuần 6:
* Mỗi thành viên tạo một file riêng theo cấu trúc: `chatlog_<ten_thanh_vien>_<nhiem_vu_chinh>.md`
* Danh sách file dự kiến:
  - `chatlog_mtuan_slides_coupon_tests.md`: Nguyễn Ngọc Minh Tuấn (Soạn Slide pptx/md, mở rộng coupon test suites)
  - `chatlog_ncuong_video_storyboard_ci.md`: Dương Nhật Cường (Storyboard video demo, Quality Gate CI)
  - `chatlog_gcuong_user_guide.md`: Trần Gia Cường (Soạn thảo User Guide tiếng Anh, 3 Failure Modes, Mermaid diagrams)
  - `chatlog_ghuy_worksheet_ai_triage.md`: Nguyễn Gia Huy (Soạn Activity Worksheet, nâng cấp AI Triage Gemini API)

### Cấu trúc khuyến nghị cho mỗi file chat log:
1. **Thông tin chung:** Họ tên, MSSV, Công cụ AI sử dụng (Claude, Gemini, Antigravity, Copilot,...), Phiên bản model.
2. **Mục tiêu công việc:** Tóm tắt yêu cầu cần AI hỗ trợ trong tuần.
3. **Các câu Prompt tiêu biểu:** Liệt kê các prompt mẫu chính xác đã gửi cho AI.
4. **Nhật ký trao đổi chi tiết (AI Response Log):** Trích xuất nội dung trao đổi quan trọng.
5. **Đánh giá & Hiệu chỉnh thủ công (Human Verification):** Ghi nhận các điểm sai lệch của AI và cách thức sinh viên tự kiểm chứng, sửa lỗi.
